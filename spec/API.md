# pupiltree-latex API specification

Every implementation (Python `pupiltree_latex`, Dart `pupiltree_latex`, JS `@pupiltree/latex`) exposes the same functions with the same semantics. The corpus in `corpus/` is the executable form of this document; when this text and the corpus disagree, the corpus wins and this text must be fixed.

Naming per language: Python `snake_case` (`to_plain`), Dart and JS `camelCase` (`toPlain`). Non-string input is returned unchanged by every string function.

Indices: Python counts code points, Dart and JS count UTF-16 units. The corpus therefore never compares positions, only strings, segment lists and finding kinds.

---

## 0. `fix(text, chemistry=true) -> text` — the one call

`fix` = `normalize` → `unwrapTypographicSpans` → `canonicalize` → `wrapBareSymbolCommands` → `wrapUnicodeChemistry` → `wrapUnicodeScripts` → `escapeTextSpecials` → `mergeAdjacentMath`. Idempotent; non-strings pass through.

`unwrapTypographicSpans(text)` (tag `v140-a7`, since 1.4.0) replaces a `segment` math span (inline or display) whose whole body, trimmed, is a key of `TYPOGRAPHIC_SPANS` by its value: `\ldots`, `\dots`, `\textellipsis` → `…`; `\textmu` → `$\mu$`. So `leukocytes$\ldots$` → `leukocytes…`, `cells\(\ldots\)` → `cells…`, `5 $\textmu$m` → `5 $\mu$m`. `\textmu` does not become a bare `µ` and `$\cdots$` is not unwrapped: `canonicalize` wraps a bare `µ` / `⋯` back into `$\mu$` / `$\cdots$`, so those are the fixed points. Then, outside `segment` math, a padded pair `\$([ \t]*)\\(ldots|dots|textellipsis|textmu)([ \t]*)\$` that is not preceded by `\` or `$` nor followed by `$` (so `segment` did not read it as math) is replaced by its padding around the value: `wait$ \ldots $now` → `wait … now`, `5$ 	extmu $m` → `5 $\mu$ m`. Every other span (`$1, 2, \ldots, n$`, `$x \ldots$`) and all prose are copied as written.

**`chemistry`** (Python keyword-only `fix(text, chemistry=False)`, JS `fix(text, { chemistry: false })`, Dart `fix(text, chemistry: false)`; also on `canonicalize`, `fixDeep`, `canonicalizeDeep`; tag `audit4-8`): `false` never puts a bare `\ce{…}` / `\pu{…}` into a new math span (step 17 of §3 leaves a string containing `\ce`/`\pu` not followed by a letter as it is). Those commands need KaTeX's mhchem extension; a renderer with KaTeX core only (Fillers) would show a red error. Unicode chemistry (`H₂O` → `$\text{H}_{2}\text{O}$`) uses KaTeX core and is unaffected. The vanilla `typesetMath` passes `chemistry: hasMhchem()` unless the caller sets it. It is what a developer calls when they do not want to learn the six: backend write chokepoints call it on fresh model output, renderers call it on whatever is about to be displayed (the `MathText` widgets and components do so by default). It is still not a read-path rewrite of stored content served to other apps (CONTRACT §3). `fixDeep(obj)` walks a document with the CONTRACT §5 key and URL skips.

`wrapUnicodeChemistry(text)` runs on text segments only (math spans untouched). A run is `(?<![\p{L}\p{N}_])[0-9]*[a-z]?(?=[A-Z])[A-Za-z0-9()]*[S][A-Za-z0-9()S]*` where `S` = `₀₁₂₃₄₅₆₇₈₉⁰¹²³⁴⁵⁶⁷⁸⁹⁺⁻` (listed one by one: ¹²³ are U+00B9/B2/B3, outside U+2070–2079): an optional coefficient, at most one lowercase letter (the `x` of a hydrate `xH₂O`), then a capital. A letter, digit or underscore right before the run blocks it (`TRUE_FALSE⁻` stays). It must contain a subscript digit or a superscript run ending in ⁺/⁻; unbalanced trailing `)` are trimmed off and kept outside; a run right after `\` or `{` is skipped. Conversion: letters/digits/parens → `\text{…}`, subscript digits → `_{…}`, superscripts → `^{…}` (⁺→+, ⁻→-), wrapped in `$…$` and padded as in §0.1. `H₂O` → `$\text{H}_{2}\text{O}$`, `SO₄²⁻` → `$\text{SO}_{4}^{2-}$`, `Fe³⁺` → `$\text{Fe}^{3+}$`, `2H₂O` → `$\text{2H}_{2}\text{O}$`, `xH₂O` → `$\text{xH}_{2}\text{O}$`, `Water (H₂O)` → `Water ($\text{H}_{2}\text{O}$)`; `10⁸`, `mc²`, `x₁` are left to `wrapUnicodeScripts` and `H2O` is unchanged.

`wrapUnicodeScripts` (after chemistry, text segments only) turns a base of letters/digits followed by one run of Unicode super- or subscripts into math: `10⁻³` → `$10^{-3}$`, `mc²` → `$mc^{2}$`, `x₁` → `$x_{1}$` (regex `(?<![\p{L}\p{N}_])([A-Za-z0-9]+(?:\.[0-9]+)?)(<sup>+|<sub>+)`, skipped right after `\` or `{`). **Unit rule**: the base is set upright as `\text{base}` when it is in `UNIT_BASES` (`mm cm dm km nm pm um mg kg ms ns ps us mol mmol kmol rad sr cd mL kJ kW kV kN kPa MPa Pa Hz kHz MHz GHz eV keV MeV mA mV`, exported as `corpus/tables/unit_bases.json`), or when it is lowercase ASCII letters and either follows a digit plus optional spaces/tabs (`240 cm³`, `5 m²`) or follows `/` and is longer than one letter or one of `SINGLE_LETTER_UNITS` = `m s g l` (`m/s²` → `m/$\text{s}^{2}$`). So `6.022 × 10²³ mol⁻¹` → `… \text{mol}^{-1}`, `per mm³` → `per $\text{mm}^{3}$`, while `x²`, `a²`, `a/b²` stay italic. The new span is padded as in §0.1. `escapeTextSpecials` (math segments only) escapes an unescaped `%` as `\%` and an unescaped `$` inside a `\text{}`-family group as `\$`, both of which would otherwise cut the formula short. `wrapBareSymbolCommands` wraps, on text segments only, a bare argument-less symbol command (`SYMBOL_COMMANDS`: every plain `\name` in `UNICODE_MATH` except `sqrt`, plus `to le ge ne implies iff deg degree cdots dots ldots`) together with its tight cluster (§0.1): `x\leq5` → `$x\leq5$`, `\alpha_1` → `$\alpha_1$`, `3\times4\times5` → `$3\times4\times5$`, `\pi2` → `$\pi2$`. First, in the same text segment, a symbol command sitting between two stray dollars that the renderers did not read as a span (`(?<![\\$])\$(\\name)\$(?![$A-Za-z])`, e.g. `x$\leq$5` left by an older version) loses those dollars, so it is re-wrapped as `$x\leq5$`, never as `$$\leq$$`. `mergeAdjacentMath` joins inline `$…$` spans separated by nothing or by spaces/tabs into one span (`$\times$ $10^8$` → `$\times 10^8$`, `$1$$\gamma$` → `$1 \gamma$`), in one linear pass, when the spans have balanced braces and matched `\begin`/`\end` and neither contains a declaration-style switch (`DECLARATION_COMMANDS`: `\bf \it \rm \sf \tt \cal \sl \em \mit \color \displaystyle \textstyle \scriptstyle \scriptscriptstyle \tiny \scriptsize \footnotesize \small \normalsize \large \Large \LARGE \huge \Huge`, not followed by a letter; exported as `declaration_commands.json`; tag `audit4-9`), whose scope would grow to the merged neighbours (`$\forall$ $\flat$ $\bf x$` → `$\forall \flat$ $\bf x$`; `\boldsymbol{x}` takes an argument and still merges); display spans, spans with prose between them and spans that are not self-contained are untouched.

Corpus file: `corpus/fix.json` (string-function shapes); `fix` also appears in `must_not_change.functions`.

### 0.1 Tight clusters and span padding (every step that creates a span)

The renderers do not accept a closing `$` that is followed by a digit (§4, pandoc rule; `str.isdigit`, so `²`, `₀` and Devanagari `५` count too). A span created right before a digit was therefore shown as text, and a later pass wrapped the `\cmd` inside it again as `$$\cmd$$` (display math in mid-sentence). Every step that writes a new `$…$` follows these rules, so `fix` output is renderable and idempotent.

**Cluster** (`canonicalize` step 14 `wrapBareUnicodeMath`, `wrapBareSymbolCommands`). The span around a symbol takes the whole tight cluster, with nothing (not even a space) between its parts:

- Right side (`clusterRight`), from the symbol on, repeatedly: a `WRAPPABLE_BARE_CHARS` symbol (a radical only with its radicand; with none the cluster ends and the glyph stays), a bare `SYMBOL_COMMANDS` command (`wrapBareSymbolCommands` only), a Unicode script run (every character `UNICODE_MATH` maps to `^{…}`/`_{…}`), an ASCII script after an operand (`[_^]` + `{…}` without nested braces or `$`, or `\name`, or one ASCII letter/digit not followed by a letter), a number `[0-9]+(?:[.,][0-9]+)*`, or a standalone single ASCII letter (no letter on either side, not followed by `(`, not an uppercase letter followed by a subscript digit — that is chemistry for `wrapUnicodeChemistry`) **only right after a joining operator**.
- Left side (`clusterLeft`), **only when the cluster starts with a joining operator**: repeatedly a number (its digits, `.` and `,`; refused when the character before it is `\ ^ _ $`, the canonicalize dollar sentinel U+E001, or a letter that is part of a word), a standalone single ASCII letter (refused after `\ ^ _` or another letter), or a Unicode script run whose base is one of those (refused for an uppercase letter with a subscript: chemistry). Never into a math span or an earlier cluster.
- Joining operators: `JOINING_CHARS` = `×÷±∓≤≥≠≈≡∼≃≅∝≪≫→←↔⇒⇐⇔⇌↦∈∉⊂⊃⊆⊇∪∩∧∨` and `JOINING_COMMANDS` = their commands plus `le ge ne to implies iff` (exported as `joining_chars.json`, `joining_commands.json`). Other symbols (`·`, `√`, and Greek outside a Greek word) take numbers and scripts to their right only: `µs`, `kΩ`, `J·s` and `2√3` keep their letters and coefficients outside (`$\mu$s`, `k$\Omega$`, `J$\cdot$s`, `2$\sqrt{3}$`).
- **Greek words** (`greekWordAt(text, k, mask)`; audit round 3, tag `audit3-greek-word`). A maximal run with no whitespace, outside math, of `GREEK_MATH_LETTERS` (`αβγδεζηθικλμνξπρστυφχψωΓΔΘΛΞΠΣΥΦΨΩϵϑϖϱςϕℏ`, exported as `greek_math_letters.json`; accented Greek and Latin-looking capitals such as `Ε` are not in it), ASCII letters, ASCII digits (`.`/`,` only between two digits) and Unicode script characters, that contains at least one Greek math letter and at least one ASCII letter or digit, is one cluster: `2πr` → `$2\pi r$`, `fλ` → `$f\lambda$`, `hν` → `$h\nu$`, `Δx·Δp` → `$\Delta x\cdot\Delta p$`, `ωt` → `$\omega t$`, `ρL` → `$\rho L$`, `2πrh` → `$2\pi rh$`, `πr²` → `$\pi r^{2}$`, `2.5λ` → `$2.5\lambda$`. It is refused (the rules above apply unchanged) when: it contains 3+ ASCII letters in a row (`αβγtest`, `Thetaα`, `λmax`, `sinθ`); it contains 3+ Greek math letters in a row; it contains an uppercase ASCII letter followed by a Unicode subscript (chemistry, `ΔH₂O`); the whole run fully matches the unit pattern `[0-9]*([.,][0-9]+)*([kMGTmμµnp]?Ω(c?m)?|[μµ](<GREEK_UNIT_SYMBOLS>|Ω)?)<scripts>*` with `GREEK_UNIT_SYMBOLS` = `s m g l L A V W F H J C K T N S M Pa Hz Wb eV mol` (longest first; exported as `greek_unit_symbols.json`), so `µs`, `kΩ`, `3 MΩ`, `mΩ`, `10Ω`, `5μs`, `10kΩ`, `Ωm`, `μN` keep `$\mu$s`, `k$\Omega$`, …; the character before the run is a letter or digit of any script (`२π`), `\ ^ _ { $` or the canonicalize dollar sentinel U+E001 (`q_π`, `e^{iπ}`, `\$5π`); or the character after the run is a letter or digit of any script (`πक`, `λόγος`). A math-span character on either side (masked) is a boundary, not a refusal. In `wrapBareUnicodeMath`, a Greek math letter whose word is accepted (and starts at or after the end of the previous span) starts its cluster at the word start; `clusterRight` then consumes the whole word at any position where it meets a Greek math letter or an ASCII letter/digit whose accepted word starts at or after the cluster start (before trying its other branches), so a word joins after a joining operator (`x≤2πr` → `$x\leq2\pi r$`) and ASCII scripts after it join too (`πr^2` → `$\pi r^2$`). `convertCluster` puts a space only between a `\cmd` and a following letter (`$2\pi r$`, `$2\pi$`).
- Conversion (`convertCluster`): symbols → their `UNICODE_MATH` command, a radical with its radicand → `\sqrt{…}`, a run of super- or subscripts → one `^{…}`/`_{…}`, everything else as written; a space only where a `\cmd` would run into a letter.

Examples: `3×4×5=60` → `$3\times4\times5$=60`, `x≤5` → `$x\leq5$`, `3.14×10⁻⁵` → `$3.14\times10^{-5}$`, `n→∞` → `$n\rightarrow\infty$`, `ε₀` → `$\epsilon_{0}$`, `σ₁₂` → `$\sigma_{12}$`, `x²≤5` → `$x^{2}\leq5$`, `CuSO₄·5H₂O` → `$\text{CuSO}_{4} \cdot5 \text{H}_{2}\text{O}$` (after chemistry and merging). Digits that touch no symbol are never moved: `2.5583`, `1,00,000`, `₹2,50,000`, `9:3:3:1`, `45°` stay byte-identical.

**Padding** (`wrapCluster`, and the chemistry and script wrappers): a new span gets one space before it when the character before is an unescaped literal `$` (text, not a span delimiter), and one space after it when the character after is a literal `$` or a digit (`isdigit`, which a cluster could not take, e.g. `x≤५` → `$x\leq$ ५`). A literal `$` next to a span would otherwise form `$$`.

**Structural commands** (`canonicalize` step 15): a number right after the command's extent joins the span (`\sqrt{2}3` → `$\sqrt{2}3$`); a digit it cannot take gets a space; the command is left as prose when an unescaped literal `$` (not a span delimiter) is directly before it or after its extent (`$\frac{1}{2}` with no closer stays as written).

## 1. `repair(text, guessWhitespace=true) -> text`

Undo JSON-escape damage to LaTeX commands and drop unrenderable control characters. Lossless where it acts.

Algorithm (single left-to-right pass, then a final strip):

0. A whole ANSI CSI sequence `ESC [ [0-?]* [ -/]* [@-~]` (terminal bold/colour codes, `\x1b[1mRecall Prompt 1:\x1b[0m` → `Recall Prompt 1:`) is removed first, in both forms (tag `audit4-5`); removing only the ESC left `[1m` in the text.
1. `U+0008` (backspace) → `\b`; `U+000C` (form feed) → `\f`, when a letter follows. A bare one has no command to go back to and is dropped in step 4 (script_editor #420 rule; Backend restored unconditionally).
2. `U+000B` (vertical tab) → `\v` only when the maximal `[A-Za-z]+` run right after it, prefixed with `v`, is in `KATEX_COMMANDS` (e.g. `<VT>ec{F}` → `\vec{F}`).
3. When `guessWhitespace` is true: `U+0009`, `U+000A`, `U+000D` → `\t`, `\n`, `\r` when the maximal `[A-Za-z]+` run right after it, prefixed with `t`/`n`/`r`, is in `LATEX_COMMANDS_BEHIND_JSON_ESCAPES` (the narrow, unambiguous set: `theta`, `times`, `text…`, `rho`, `right…`, `nabla`, `neq`, … but deliberately not `nu`, `ne`, `ni`, `not`); or when the run is followed by `:` and letter + run is in `SCRIPT_LABELS` (`<TAB>eacher:` → `\teacher:`); or when the position is inside a `$…$` span (odd count of unescaped `$` before it) and exactly one of `n`/`t`/`r` + run is in `JSON_WHITESPACE_COLLISION_COMMANDS` (`$x <LF>ightarrow y$` → `\rightarrow`). Otherwise the whitespace is kept.
4. Every other C0 control (`U+0000`–`U+001F` except TAB/LF/CR) and `U+007F` is removed.

`guessWhitespace=false` is the read-path form (Backend #1595 "A8"): only steps 0, 1, 2 and 4. It restores `<FF>rac` → `\frac`, `<BS>eta` → `\beta` and `<VT>ec` → `\vec` (a form feed, backspace or vertical tab is never content) and keeps every TAB, LF and CR, so `<TAB>ext{H}` stays as stored. `guessWhitespace=true` is the opt-in that also restores TAB/LF/CR, and only before an unambiguous command: `<TAB>ext` → `\text`, `<TAB>imes` → `\times`, `<TAB>heta` → `\theta`, `<TAB>an` → `\tan`, `$x <LF>ightarrow y$` → `\rightarrow` inside a closed span, never `<LF>u` (`\nu` is also a line break before "u"). Corpus tag `audit4-12` pins both forms.

Idempotent. Fast-path: return the input when it contains no control character.

## 2. `normalize(text) -> text`

Display-safe normalisation for any client before rendering. Content-preserving (no heuristic wrapping), idempotent. Steps in this exact order:

1. `repair(text)`.
2. `fixMojibake(text)` — the **table** fixer (deterministic, identical in all languages):
   a. If the text contains `Ã` or `Â`: re-encode as Latin-1 bytes (characters > U+00FF make this step a no-op) and decode as UTF-8 leniently; keep the result only if it has fewer bad characters (`U+FFFD`, `Ã`, `Â`) than the input.
   b. Apply the replacement table `MOJIBAKE_TABLE` (Greek, math symbols, arrows, sub/superscripts, punctuation, currency `€ £ ¥ ₹ ¢` — see `corpus/tables/mojibake_table.json`), longest key first. The table runs before anything could wrap a Unicode symbol, so the `¬` of `â‚¬` (the cp1252 reading of `€`) is never turned into `$\neg$`: `â‚¬5` → `€5`, `â‚¹500` → `₹500`, `Â£5` → `£5`.
   Before (a), and even for ASCII-only text, decode HTML entities: the named ones in `HTML_ENTITIES` plus `&#NNN;` / `&#xHH;` numeric references (`a &amp; b` → `a & b`); unknown names stay.
   c. Convert NBSP (`U+00A0`) to a space, then remove C1 controls (`U+0080`–`U+009F`) and lone surrogates; apply the context rules for `â…digits` → `√…` and lone `Ï` → `π`/`ω`; then collapse a doubled `ππ`, `ωω`, `√√` **only when a context rule produced one of the pair**. Implementation: before the context rules, every `π`, `ω`, `√` already present (typed, or produced by the table) is replaced by a private-use placeholder (`U+E020`, `U+E021`, `U+E022`); after them, `cc` → `c`, placeholder + `c` → placeholder and `c` + placeholder → placeholder for each of the three characters, then the placeholders are restored. So `ππ`, `ωω`, `√√2` and `Ï€Ï€` (→ `ππ`) keep both characters, while `2Ïπ` → `2π`.
   Skip the whole step when the text has no character ≥ U+0080.
3. `normalizeDelimiters`: `\[…\]` → `$$…$$`, then `\(…\)` → `$…$`. An opener or closer preceded by a backslash (`\\[2pt]`, `\\(`) is not a delimiter. Non-greedy, may span lines. Inside an inline span, every run of whitespace containing a newline collapses to one space and the content is trimmed.
4. `stripOrphanDelimiters`: remove any remaining `\(`, `\)`, `\[`, `\]` (not preceded by a backslash).
5. `escapeCurrency` — line by line, left to right (pandoc rule):
   - `\$` and `$$…$$` blocks are copied through (a `$$` block runs to the next `$$` or end of line).
   - A single `$` followed by a digit is currency **unless** the next unescaped single `$` on the same line is a valid closer: not followed by a digit, and either not preceded by a space or tab or the content between the two is a **formula** (`isFormula`, tag `audit4-6`): after replacing each `\name` by a space and right-trimming, it is only `[0-9A-Za-z+\-*/=<>().,^_ \t]`, has no two ASCII letters in a row, and has an operator `[+\-*/=<>^_]` or a command, and a letter or a command. So `Compute $2x + 3 $.` keeps its dollars (canonicalize step 10a then trims it), while `Prices: $10, $20`, `$5 and $10` and `costs $5 and x $` stay currency. Currency `$` becomes `\$`; a valid span is copied whole so its closer is not re-examined.
   - Examples: `$5000 and $\frac14$` → `\$5000 and $\frac14$`; `$5-$10` → `\$5-\$10`; `costs $5.` → `costs \$5.`; `$2x + 3$` unchanged.
     A `$` not followed by a digit opens a span that is copied through to the next unescaped `$` (if any), so that closer is never re-examined as a currency opener (`$\sqrt$2` stays as it is).
     5a. `trimPaddedSpans` (tag `audit6-1`, since 1.3.0): canonicalize step 10a (§3), run on the output of step 5, so an escaped amount is never paired. `Solve $ x + 1 = 0 $ for x.` → `Solve $x + 1 = 0$ for x.`, `Compute $2x + 3 $.` → `Compute $2x + 3$.`, `$ x + 1$` → `$x + 1$`. `segment` keeps pandoc's closer rule (§4), so without this step a stored padded formula would display as raw text. Currency wins as in step 10a: `I paid $ 5 and got $ 3`, `Rs $5 and $10`, `where $ v $ is speed` (one letter is not clearly math) and `pay $ x + 1 $5 now` (closer before a digit) are unchanged.
6. `decodeEscapesOutsideMath`: a position is protected when it lies in a `segment` math span (§4) **or** in a regex span (`$$…$$` any content; `$…$` where content has no bare `$` and no newline, `\$` allowed; an opener preceded by a backslash does not open). Decoding is lossy, so either reader suffices (tag `audit5-8`): in `a $ $\nu$ b` the regex pairs `$ $` and `segment` renders `$\nu$`, and the `\nu` used to become a newline + `u`; a padded `$ x \ne y $` that step 5a did not trim (`$ x \ne y $5`) is still protected. In unprotected parts only, the two-character sequences `\r\n`, `\n`, `\r` → newline and `\t` → tab, **unless** the backslash starts a known command: the maximal `[A-Za-z]+` run after the backslash is in `JSON_WHITESPACE_COLLISION_COMMANDS` (= every KaTeX command starting with `n`, `t` or `r` of length ≥ 2, plus `textmu`, `textsuperscript`, `textsubscript`, `nicefrac`). So `\nStatement` decodes, `\neq`, `\nu`, `\theta`, `\text{x}`, `\right` do not. A backslash + letters immediately followed by `:` is a lesson-script label (`\teacher:`, `\type:`, `\read:`) and is never decoded, whatever the word; the same rule applies in `escapeLatexForJson`, and `repair` restores a decoded label (`<TAB>eacher:` → `\teacher:`) when the word is in `SCRIPT_LABELS`.

`normalize` never wraps anything in `$` (step 5a only moves an existing pair's dollars), never converts Unicode to LaTeX and never touches URLs or `{{IMAGE:…}}` markers (it has no step that could).

## 3. `canonicalize(text) -> text`

The write-time sanitiser for fresh Class A model output (Backend `sanitize_latex_text`, 15 steps). Heuristic; idempotent; **never on the read path**.

1. Return unchanged if the whole string is a URL (`^\s*(https?|gs|data|blob)://\S+\s*$`, case-insensitive).
2. Stash every `{{IMAGE:…}}` marker and every URL embedded in prose (`(?:https?|gs)://[^\s<>"'$]+`, case-insensitive; `$` excluded so a URL never swallows the math after it) under a private-use sentinel `U+E002` + `chr(0xE100 + index)` + `U+E003` (no letters, digits or `_`, so no later step can read it as a script); restore at the end, last-stashed first (a URL stashed after a marker may contain the marker's sentinel). (Backend skipped whole-string URLs only; the embedded-URL stash is this library's one widening, so `see https://a/b_c.png` keeps its `b_c`.)
3. `repair(text)`.
4. Stash `\$` under a private-use sentinel `DOLLAR_ESC` — only a `\$` preceded by an even run of backslashes (`(?<!\\)((?:\\\\)*)\\\$`, the run is kept). `\\$\frac{1}{2}$` is a line break followed by a span; stashing its `\$` once broke the span and produced `\\$$\frac{1}{2}$$`.
5. `escapeCurrency` (Backend rule, different from `normalize`'s): only when the count of unescaped `$` (a `$` preceded by an even run of backslashes) is odd; then every `$` followed by `\d[\d,]*(\.\d+)?` and then whitespace, `.,;!?)]-–—` or end-of-string becomes `\$…`. Re-stash the new `\$`.
6. Mojibake: `ftfy.fix_text` (NFC, unescape HTML, fix ligatures and widths, keep curly quotes; strings under 20 chars are padded with `abc xxx ` / ` yyy def`) in Python when ftfy is installed; otherwise the table fixer of §2. Corpus cases that need ftfy carry `"impl": ["python"]`.
7. `normalizeHomoglyphs`: `µ→μ`, `∆→Δ`, `ħ→ℏ`, `− ‐ ‒ → -`, `Ω(ohm)→Ω`, `K(kelvin)→K`, `Å(angstrom)→Å`.
8. `collapseDoubleBackslashes`: an EVEN run of backslashes (`(?<!\\)((?:\\\\)+)`) directly before any command in `COLLAPSIBLE_COMMANDS` (every KaTeX command plus `ce`, `pu`) collapses to one backslash; an odd run (`\\\frac`, a line break followed by a command) is left alone.
9. `\left{` → `\left\{`, `\right}` → `\right\}`.
10. `\(…\)` → `$…$`, `\[…\]` → `$$…$$` (non-greedy, DOTALL, backslash-guarded like §2.3 but without newline collapsing).
    10a. `trimPaddedSpans`: `Solve $ x^2 + 1 = 0 $ now` → `Solve $x^2 + 1 = 0$ now`. The renderers do not open a span on `$` + space, so the later wrapping steps used to nest a second span inside (`$ $x^2$ + 1 = 0 $`). ## 4. `segment(text) -> [Segment]`

The one tokenizer. `Segment = {kind: "text" | "math", display: bool, value: string, raw: string}`; for text segments `display` is false.

Scanning left to right; delimiter priority at each position: `$$`, `\[`, `$`, `\(`.

- An opener is escaped, and therefore literal, when preceded by an odd number of backslashes (`\$5`, `\\(`). `\\$x$` opens math (the pair `\\` is a literal backslash).
- The closer is found by the KaTeX auto-render walk: a backslash skips the next character, `{`/`}` change depth, the closer only counts at depth ≤ 0.
- Inline `$…$` extra rules (pandoc): the content must not start with whitespace, must not contain a newline, and the closer must not be followed by a digit. The FIRST candidate closer decides: if it fails, the opening `$` is literal text (so `$60 and $x^2$` keeps `$60` literal and renders `$x^2$`; the pandoc behaviour of running on to a later closer is deliberately not followed).
- `$$…$$`, `\[…\]`, `\(…\)` may span lines; `\(…\)` content is trimmed; the others are kept as written.
- An unterminated opener and everything after it is text.
- `raw` is the exact source slice (delimiters included for math). `value` is the inner content for math, and for text the slice with `\$` unescaped to `$`.
- Adjacent text is merged into one segment. Empty text segments are never emitted. Empty math (`$$`) is text.

`containsMath(text)` is true when `segment` yields a math segment or the text contains a backslash followed by a letter.

`isPlainProse(text)` is the renderer fast path: true when the text contains none of `\ $ * ~ \` | [ ] < > # ⸻ 【`, no `\r`, no blank line, no `--`, and no leading indentation or list marker (`- `, `* `, `1. `) on any line. Non-strings are not plain prose.

## 5. `toPlain(text, style="text") -> text`

LaTeX to plain Unicode text (Backend `latex_to_plain`). Every style first runs `repair(text)` with `guessWhitespace=true`, as `fix` does through `normalize` (tag `audit5-3`): `Area <FF>rac{1}{2}` → `Area 1/2`, `3 <TAB>imes 4` → `3 × 4`, `$x <LF>ightarrow y$` → `x → y`, `<BS>eta` → `β`; TAB/LF/CR before anything else stay whitespace. It then trims padded spans as `normalize` step 5a does, with the dollars `escapeCurrency` reads as money masked first (tag `audit6-2`): `Compute $2x + 3 $.` → `Compute 2x + 3.`, `Rs $5 and $10 for $ x^2 $` → `Rs $5 and $10 for x²`. Between the two (tag `v140-a6`, since 1.4.0) mojibake is repaired: `text`, `pdf` and `tts` run `fixMojibakeTable` exactly as `normalize` step 2 does (`Value of Ï€` → `Value of π`, `a &amp; b` → `a & b`); `compare` runs `unescapeHtmlEntities` and then `fixMojibakeCore` (the same fixer without its entity step). Styles: `"text"` (accents dropped, for canvas and reports), `"pdf"` (accents marked: `\vec{F}` → `F⃗`, `\vec{AB}` → `vec(AB)`), `"tts"` (spoken English, see below), `"compare"` (one form for answer comparison, see below; tag `audit4-7`). Any other style raises.

`text`/`pdf` algorithm:

0. **Bare chemistry** (`text` and `pdf` only; tag `v140-a9`, since 1.4.0): `bareChemistryToUnicode` writes a chemistry-shaped token in prose with Unicode subscripts: `H_2SO_4` → `H₂SO₄`, `Na_2CO_3` → `Na₂CO₃`, `Ca(OH)_2` → `Ca(OH)₂`. A token starts at an uppercase ASCII letter or `(` whose previous character is not an ASCII letter, digit, `_` or `\`; it is a run of element symbols (`ELEMENT_SYMBOLS`, the 118 symbols, two-letter match first) and one level of `(…)` groups of them, each optionally followed by a digit subscript `_2` / `_{12}`; it needs at least one subscript, must not be followed by an ASCII letter, digit or `_`, and must not start inside a `segment` math span. So `lo_0`, `v_avg`, `E_1`, `Q_2`, `fallback_factual_error`, `MCQ_SINGLE`, `q_001_easy`, `XH_2O_id` and `10_A` stay as written.
1. Return unchanged when the text has none of `$`, `\`, `{`. Park `{{IMAGE:…}}` markers and restore them at the end.
   1a. **Amounts** (tags `audit5-1`, `audit5-2`): a `$` that `normalize`'s `escapeCurrency` (§2 step 5) reads as money, that lies outside every `segment` math span, and that is followed by an amount `[0-9]+([.,][0-9]+)*` not followed by `[0-9A-Za-z\\^_{]` is parked as a literal dollar (the step-3 sentinel). So `Rs $5 and $10` → `Rs $5 and $10` (the closer before a digit is not a closer), `$5` → `$5`, `costs $5.` → `costs $5.`, `Rs $5 and $x^2$` → `Rs $5 and x²`, in every style (`compare` keeps the dollar, as it always did for `\$5`). A cut-off span keeps the old behaviour: `$45m` → `45m`, `$4\sqrt{3}s` → `4√3s` (step 7).
2. Literal `\n` before an uppercase letter, whitespace or end → newline.
3. Park `\$`, `\{`, `\}` under sentinels (single private-use characters U+E012, U+E010, U+E011, so an argument reader can never take part of one); restore them at the end.
   3a. **Script labels** (tag `audit4-4`): every match of `(^|\n)([ \t]*)\\([a-z][a-z_]*):` (a lowercase word after a backslash and before `:` at a line start) is parked as U+E013 + index + U+E014 and restored at the end as `\name` in `text` style and `name` in `pdf` and `compare` (the `tts` reader also drops the backslash). The canvas reads the labels, and the command scanner read `\instruction` as `\in` + "struction" (`∈struction`). Elsewhere in a line, `\name:` is parked the same way only when `name` is in `SCRIPT_LABELS` (tag `audit5-3`: `(<TAB>ool: timer)` is repaired to `\tool:`, which the scanner read as `\to` + `ol`); any other `\cmd:` that is not at a line start is converted as before (`x \in A:` → `x ∈ A:`).
   3b. **Prose braces** (tag `audit4-2`): positions inside `$$…$$` / `$…$` (the regex `\$\$[\s\S]+?\$\$|\$[^$]+\$`, scanned once) are masked. Each remaining `{` is examined left to right; its partner is the matching `}` counting masked positions as absent. A `{` is an **argument** when the character before it is `^` or `_`, the `}` closing an earlier argument, the `]` of a `[…]` that directly follows a `\name`, or the last letter of a `\name`; or when only spaces/tabs separate it from a `\name` whose name takes an argument (fractions, binomials, `\sqrt`, wrappers, colour, dropped-with-argument, accent commands, `\begin`, `\end`); an argument group is skipped whole (an unclosed one ends the pass). Otherwise the `{` is **prose**: unclosed, it is parked as a literal `{`; closed, when its content is longer than one character and contains one of `, : ; |`, both braces are parked as literals and the scan continues inside; else it is LaTeX grouping (`1{,}000`, `{x}`) and skipped. So `A = {1, 2, 3}`, `the set {a, b}`, `{x | x > 0}` and `\mindmap: {"central": …}` keep their braces; `{\alpha, \beta}` → `{α, β}`. A `}` with no opener is still dropped.
4. Strip `$$…$$` and `$…$` delimiters (keep inner content). Amounts were parked in step 1a, so only real spans and stray non-amount dollars pair here.
5. Single recursive pass with a balanced-brace reader:
   - `\frac{a}{b}` (and dfrac/tfrac/cfrac) → `a/b` (tag `audit4-3`): each part is bare when, stripped, it is a number `[0-9]+(\.[0-9]+)?`, one letter (`[^\W\d_]`, any script) or one parenthesised group, else `(part)`: `\frac{22}{7}` → `22/7`, `\frac{a+b}{c+d}` → `(a+b)/(c+d)`, `\frac{2a}{3}` → `(2a)/3`, `\frac{\frac{1}{2}}{3}` → `(1/2)/3`; a numerator that is a negative number `[-−][0-9]+(\.[0-9]+)?` is bare too (tag `v140-a5`: `\frac{-1}{4}` → `-1/4`), a negative denominator keeps its parentheses (`\frac{y+1}{-2}` → `(y+1)/(-2)`). The whole fraction is parenthesised when it touches a term: the last converted character before it is a letter/digit (`isalnum`) or `/`, or the next source character after it is a letter/digit or one of `( \ ^ _ {` (a closing `\)` or `\]` is not a term, tag `v140-a3`: `\(\frac{1}{2}\)` → `1/2`): `2\frac{1}{2}` → `2(1/2)`, `\frac{1}{2}mv^{2}` → `(1/2)mv²`; `\binom{n}{k}` → `C(n, k)`; each argument is a brace group, a control word or one character, leading spaces skipped.
   - `\sqrt{x}` → `√x` when `x` is one token or one parenthesised group, else `√(x)`; `\sqrt[3]{8}` → `³√8`; a non-superscriptable index → `(idx)√…`.
   - Wrapper commands (`\text \textit \textbf \textrm \textsf \texttt \textsc \textup \textnormal \mathrm \mathit \mathbf \mathsf \mathtt \mathbb \mathcal \mathfrak \mathscr \boldsymbol \bm \operatorname \emph \mbox \hbox \ce \boxed \fbox \cancel \bcancel \xcancel \sout \underbrace \overbrace \pu`) → their argument.
   - `\color`, `\textcolor`, `\colorbox` → drop the colour argument, keep a following brace argument.
   - `\hspace \vspace \phantom \hphantom \vphantom \label \tag \kern \mkern \mspace \hskip` → dropped with their argument.
   - Accents `\vec \overrightarrow \overleftarrow \hat \widehat \bar \overline \dot \ddot \tilde \widetilde` → argument (style `text`) or argument + combining mark / `name(arg)` (style `pdf`); `\check \breve \acute \grave \underline \mathring` → argument.
   - `\left \right \big \Big \bigg \Bigg \bigl \bigr … \middle` → dropped (a following `.` is dropped too); `\hline \nonumber \notag \textstyle \scriptstyle \displaystyle \scriptscriptstyle` → dropped.
   - `\begin{env}…\end{env}`: matrices → `[a b; c d]` (`vmatrix` → `|…|`, `Vmatrix` → `‖…‖`), `cases` → `a, x>0; b, x≤0`, others → rows joined by `; `.
   - Known commands → the Unicode in `LATEX_CMD_MAP` (`\alpha`→`α`, `\times`→`×`, `\circ`→`°`, `\rightarrow`→`→`, `\leq`→`≤`, `\sin`→`sin`, `\quad`→` `, `\prime`→`′`, …). A command that runs into the next word (`\colonN`) is split at the longest known prefix (minimum 2 letters). Unknown commands lose the backslash.
   - `^{…}` / `_{…}` (or a single token / control word) → Unicode super/subscript when every character has one (`10^{-15}` → `10⁻¹⁵`, `H_{2}` → `H₂`), `°′″‴` pass through, a single other character → `^x`/`_x`, otherwise `^(…)`/`_(…)`.
   - Spacing `\, \; \: \> \ ` and `\\` → one space; `\!` → nothing; `\% \& \# \_` → the character; `\( \) \[ \]` → nothing; an orphan backslash → nothing.
   - `{…}` → converted content; a stray `}` → nothing.
6. Collapse runs of spaces/tabs to one space (newlines kept).
7. If the result has an odd number of `$`, drop a leading or trailing one.

U+2212 `−` is kept as written by `text` and `pdf` (tag `audit4-10`); only `compare` folds it.

`compare` style (tag `audit4-7`): the `text`/`pdf` algorithm without the step-1 fast path, labels without the backslash, then: `−` (U+2212), `‐` (U+2010), `‒` (U+2012) → `-`; `× · ⋅ ∗` → `*`; `÷` → `/`; every run of Unicode superscripts (`⁰-⁹ ⁺ ⁻ ⁼ ⁽ ⁾ ⁿ ⁱ`) → `^` + the ASCII characters, every run of Unicode subscripts (`₀-₉ ₊ ₋ ₌ ₍ ₎ ₐ ₑ ₒ ₓ ₕ ₖ ₗ ₘ ₙ ₚ ₛ ₜ`) → `_` + the ASCII characters; whitespace runs → one space, trimmed; one optional space on each side of `+ - * / = < > ^ _ ( ) , { } [ ]` removed. A typed answer and the same value in LaTeX give the same string: `1/3` = `$\frac{1}{3}$` → `1/3`; `x^2` = `$x^2$` = `x²` → `x^2`; `H_2O` = `$H_2O$` = `H₂O` = `$\text{H}_{2}\text{O}$` → `H_2O`; `10^-3` = `$10^{-3}$` → `10^-3`; `90°` = `$90^\circ$` → `90°`; `−3` = `-3` → `-3`; `2 \times 3 = 6` = `2*3 = 6` → `2*3=6`. Case and words are kept (`New Delhi`). Comparing two answers is `toPlain(a, "compare") == toPlain(b, "compare")`.

Since 1.4.0 `compare` also (tags `v140-a1`–`v140-a5`):

- decodes HTML entities with `unescapeHtmlEntities` before anything else (see below), so `5&thinsp;m` = `5 m`, `2&ndash;3` = `2-3`, `&#x3C0;r` = `πr`;
- in the step-1a amount pass, removes an escaped `\$` whose amount runs into a unit letter, `^`, `_`, `{` or a command (`\\\$(?=[0-9]+([.,][0-9]+)*([A-Za-z^_{]|\\[A-Za-z]))`): `\$0.008Wb` → `0.008Wb`, `\$4\sqrt{3}s` → `4√3s`; `\$5`, `\$5 each` and `\(\$5\)` keep `$5`;
- after step 7 removes every `$` still present (all spans were stripped and amounts are parked, so it is an unpaired half): `3.2$ m` → `3.2 m`, `$x$ and 5$ more` → `x and 5 more`; a stray `\(`, `\)`, `\[`, `\]` is already dropped by step 5;
- before folding, removes one leading **option label** `^\s*(\([A-Ha-h]\)|[A-Ha-h][).:])\s+(?=\S)`: `B) 8-celled` → `8-celled`, `(A) 2/4` → `2/4`, `C. x^2` → `x^2`, `D: 5` → `5`, `a) $\frac{1}{2}$` → `1/2`. The label is kept when the rest is a lone letter `[A-Za-z]` (`a: b` stays `a: b`, `A) B` → `A)B`), so an answer is never turned into an option letter. A label needs whitespace and an answer after it: `B`, `(C)`, `C.x` and `Vitamin C. Yes` are unchanged. `text`/`pdf`/`tts` keep labels;
- folds each character through `COMPARE_FOLD` (exported as `corpus/tables/compare_fold.json`, so the three languages agree without platform NFKC) before the script runs: `− ‐ ‑ ‒ –` → `-`, `× · ⋅ ∗` → `*`, `÷ ⁄ ∕` → `/`, `º` → `°`, plus the compatibility decomposition (NFKC, but stopping at a Unicode super/subscript so `㎤` → `cm³` → `cm^3`) of NBSP, `µ`, `¼ ½ ¾`, U+2000–200A, `‥ …`, U+202F, U+205F, letterlike symbols U+2100–214F (`℃` → `°C`, `Ω` U+2126 → `Ω`, `K` U+212A → `K`, `Å` U+212B → `Å`), number forms U+2150–215F and U+2189, U+3000, CJK unit squares U+3380–33FF (`㎝` → `cm`), ligatures U+FB00–FB06 and full-width forms U+FF01–FF5E, U+FFE0–FFE6 (`ｘ＝５` → `x=5`). A folded value that starts with a digit and contains `/` (a vulgar fraction) gets a space when the previous output character is an ASCII digit: `1½` → `1 1/2`. So `x²` = `$x^2$`, `H₂O` = `$H_2O$`, `5 µm` = `5 $\textmu$m` = `5 μm`, `…` and `$\ldots$` → `...`.

`unescapeHtmlEntities(text)` (tag `v140-a2`, since 1.4.0) is Python's `html.unescape` in every language: references match `&(#[0-9]+;?|#[xX][0-9a-fA-F]+;?|[^\t\n\f <&#;]{1,32};?)`; a numeric one is looked up in `HTML_NUMERIC_OVERRIDES` (`html._invalid_charrefs`: `&#0;` → U+FFFD, `&#13;` → CR, `&#128;`–`&#159;` → Windows-1252), then a surrogate or a value above U+10FFFF → U+FFFD, then a noncharacter or control (`0x1–0x8`, `0xB`, `0xE–0x1F`, `0x7F–0x9F`, `0xFDD0–0xFDEF`, `xFFFE`/`xFFFF` in any plane) → nothing, else the character; a named one is looked up whole in `HTML5_ENTITIES` (`html.entities.html5`, 2,231 names including the 106 legacy ones without `;`), else the longest prefix of length ≥ 2 that is a name (`&ampx` → `&x`, `&notit;` → `¬it;`), else it stays. One round: `&amp;lt;` → `&lt;`. `normalize` (§2 step 2) keeps its own small `HTML_ENTITIES` set, decoded up to three rounds.

`tts` style (agents `_clean_script_for_tts`): each math segment is read with a balanced-brace walker, then word rules. Walker: `\frac`/`\dfrac`/`\tfrac`/`\cfrac{a}{b}` → `(a over b)` at any nesting depth; `\sqrt{x}` → `square root of x`, with the radicand in parentheses when it holds a space, `+`, `-` or `=` (`\sqrt{x^{2}+y^{2}}` → `square root of (x squared+y squared)`), `\sqrt[3]{8}` → `cube root of 8`, `\sqrt[n]{x}` → `nth root of x`; font and text wrappers (`\text \textbf \textit \textrm \textsf \texttt \textnormal \textup \textmd \emph \mathrm \mathit \mathbf \mathsf \mathtt \mathbb \mathcal \mathfrak \mathscr \boldsymbol \bm \operatorname \mbox \hbox \boxed \fbox`) → their content; a wrapper whose content is an element (`[A-Z][A-Za-z()]*`) followed by a digit subscript and/or a charge superscript is read as chemistry (`\text{H}_{2}\text{O}` → `H 2 O`, `\text{SO}_{4}^{2-}` → `SO 4 2 minus`, `\text{Fe}^{3+}` → `Fe 3 plus`); `\text`/`\mathrm` content with `_`/`^` and `\ce{…}`/`\pu{…}` content are read as chemistry too (digits after a letter or `)` and `_n` spoken as `n`, `^{n±}` as `n plus/minus`, `->` → `gives`, `<-` → `comes from`, `<=>`/`<->` → `is in equilibrium with`: `\ce{H2O}` → `H 2 O`, `\mathrm{H_2O}` → `H 2 O`); `\left \right \middle \big…\Bigg…` and style commands are dropped (with a following `.`); `\hspace \vspace \phantom \label \tag \color` are dropped with their argument; `\textcolor`/`\colorbox` keep their second argument; `\begin{…matrix}` → `matrix with rows 1, 2; 3, 4`, `cases` → `x, x > 0; -x, x less than or equal to 0`, other environments → rows joined by `; `; `\%` → `percent`, `\{`/`\}` → `(`/`)`, `\& \# \_ \$` → the character, `\\`, `&`, `\quad` and the spacing escapes → a space. Since 1.4.0 (tag `v140-a8`): a math segment whose whole body, trimmed, is `\ldots`, `\dots`, `\cdots` or `\textellipsis` is read as `…` (a pause: `leukocytes$\ldots$` → `leukocytes…`) and one that is `\textmu` as `micro`; inside a longer formula those commands are the words `dots` / `micro` (`$1, 2, \ldots, n$` → `1, 2, dots, n`; a space before `,` or `;` is removed). A text segment first reads a bare single-letter subscript, `(^|[^A-Za-z0-9_\\])([A-Za-z])_(\{[A-Za-z0-9]+\}|[A-Za-z0-9])(?![A-Za-z0-9_^{])`, as `x sub n` (`the term x_{n}` → `the term x sub n`, `E_n` → `E sub n`); `lo_0`, `v_avg`, `H_2O`, `H_{2}O`, `x_0^2` and `fallback_factual_error` stay. Word rules: `^{\circ}` → `degrees` (with a space after: `50^\circ C` → `50 degrees C`); a text segment reads a bare `^\circ` / `^{\circ}` the same way (` degrees`, plus a space when a letter or digit follows: `50^\circ C`, `50^{\circ}C` → `50 degrees C`), and a text segment that starts with a letter or digit right after a math segment read as `… degrees` gets a space (`$50^\circ$C` → `50 degrees C`); after a word character, `)`, `]` or `|`: `^2`/`^{2}` → ` squared`, `^3`/`^{3}` → ` cubed`, `^{n}`/`^n` → ` to the power n`, `_{n}`/`_n` → ` sub n`; `\times` → `times`, `\div` → `divided by`, `\pm` → `plus or minus`, `\leq`/`\le`, `\geq`/`\ge`, `\neq`/`\ne` → `less than or equal to` / `greater than or equal to` / `not equal to`, `\cdot` → `times`, `\approx` → `approximately`, `\infty` → `infinity`, `\int` → `integral of`, `\sum` → `sum of`; every other command → its name; every word gets a space on both sides (`4\pi` → `4 pi`); braces and stray backslashes removed; spaces collapsed, no space after `(` or before `)`; one pair of parentheses around the whole result dropped. A text segment containing a backslash goes through the walker too (with `&` kept), so bare `\frac{1}{2}` in prose reads `(1 over 2)`. Then leftover `\cmd` lose the backslash; `**x**`/`*x*` → `x`; runs of spaces → one; 3+ newlines → 2; trimmed. The result never contains a backslash command, `\text`, `&` or a matrix environment name.

## 6. `audit(text) -> [Finding]`

Read-only. `Finding = {kind, position, snippet}`. Kinds, in the order they are checked:

| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `control_char`             | any C0 except TAB/LF/CR; or TAB/LF/CR followed by letters spelling a `LATEX_COMMANDS_BEHIND_JSON_ESCAPES` command (for LF the run must be ≥ 3 letters); or, inside a `$…$` span, TAB/LF/CR followed by letters spelling a `JSON_WHITESPACE_COLLISION_COMMANDS` command under any of `n`/`t`/`r` |

## 7. JSON transport (`escapeLatexForJson`, `loadsLatexAware`)

`escapeLatexForJson(jsonText)` rewrites a raw model response so a standard JSON parser cannot turn LaTeX into control characters. Inside string values (tracking `"` with escape awareness, resetting math state at each string end):

- `\"`, `\\`, `\/`, `\uXXXX` are kept.
- `\n`, `\t`, `\r` are kept as JSON escapes unless the letters after the backslash spell a command. "In math" is decided with `segment` on the raw string body (not `$` parity, so an unpaired currency dollar does not flip it). Inside math the full `JSON_WHITESPACE_COLLISION_COMMANDS` vocabulary decides; outside math `PROSE_ESCAPE_COMMANDS` decides, which is the same vocabulary minus `nu ne ni not` (production prose carried "\nu = -25 cm", "\ne) No enzyme", "\ni) Presence of" as real line breaks). A letters run followed by `:` is a lesson-script label and always a command. A spelled command gets its backslash doubled. `normalize`'s escape decoder uses the same `PROSE_ESCAPE_COMMANDS`.
- `\b` and `\f` are always doubled (never JSON escapes here).
- Every other backslash (letter, digit, space, brace, …) is doubled: none of those is a JSON escape, and leaving `\ ` or `\1` would make the parser raise.

`loadsLatexAware(jsonText)` = parse(escapeLatexForJson(jsonText)), falling back to a plain parse. Python also offers `loadsModelJson` (strict=False, no fallback).

## 9. Corpus files

`corpus/<function>.json`: `{"function": "...", "cases": [{"id", "input", "expected", "tags", "impl"?, "style"?, "property"?, "source"?, "note"?}]}`. `impl` defaults to all three. `opts` (fix and canonicalize only) holds keyword options, e.g. `{"chemistry": false}`. `expected` is a string (repair, normalize, canonicalize, to_plain), a list of segments (segment), a list of kinds (audit), or a JSON value (json_transport). `property: "idempotent"` means `f(f(x)) == f(x)` is asserted instead of a value. `corpus/must_not_change.json` lists inputs that every named function must return unchanged.
